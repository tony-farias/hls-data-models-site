# Industry Data Models

Interactive entity-relationship diagrams for common industry data models.

**Health and Life Sciences**

- Commercial CRM (Veeva Vault CRM)
- Safety / Pharmacovigilance (Veeva Vault Safety)
- Quality / QMS (Veeva Vault Quality)
- Clinical / CTMS (Veeva Vault Clinical)
- Health Cloud Benefits Verification (Salesforce, illustrative mock)
- Finance / Gross-to-Net (Oracle NetSuite)
- Quality / HEDIS Measures

**Consumer Packaged Goods**

- Walmart Scintilla US Cloud Feeds: Sales & Demand, Inventory & Availability, Item/Store & Assortment, Supply Chain, Forecasting, E-commerce, Pricing & Funding, and the combined Monday Morning App footprint

Each tab groups tables into data domains, draws the relationships inferred from each source's naming conventions, and lets you filter the full table index. Every domain's **Get Genie Skill** button opens the matching skill in [genie-code-templates](https://github.com/tony-farias/genie-code-templates).

This is a static copy of the HLS Data Model Explorer Databricks App, published with GitHub Pages. Links that only work inside a Databricks workspace (Unity Catalog tables and Genie spaces) are removed here.
